After — WebSite entity with Pagefind SearchAction

  <meta name="description" content="Agentic AI Wiki — bilingual (en/zh) durable mental models, deep dives, and a field guide for the practitioner building with LLMs.">
  <meta property="og:title" content="Agentic AI Wiki">
  <meta property="og:description" content="Bilingual durable mental models and deep dives for the practitioner building with LLMs.">
  <meta property="og:type" content="website">
+ <script type="application/ld+json">
+ {
+   "@context": "https://schema.org",
+   "@type": "WebSite",
+   "@id": "https://agentic-ai-wiki.vercel.app/#website",
+   "name": "Agentic AI Wiki",
+   "url": "https://agentic-ai-wiki.vercel.app/",
+   "inLanguage": ["en", "zh"],
+   "description": "Bilingual durable mental models, deep dives, and a field guide for practitioners building with LLMs.",

+     },
+     "query-input": "required name=search_term_string"
+   }
+ }
+ </script>

C. Google Rich Results — simulated breadcrumb trail

How Google renders the BreadcrumbList in a SERP snippet
Simulated Google search result
agentic-ai-wiki.vercel.app › concepts › what-is-an-agent
What Is an AI Agent? | Agentic AI Wiki
The agent loop explained: perceive, plan, act, observe — and when that loop is worth the complexity. Durable mental model for practitioners building with LLMs.

The breadcrumb trail replaces the raw URL in the green line, increasing snippet real-estate and click-through rate. Deep-dive pages gain a four-item trail: Home › Deep Dives › Retrieval & RAG › Advanced RAG Architectures.

Implementation note: In SectionEntryLayout.astro, the existing jsonLd const is restructured into a @graph array containing both the TechArticle node and the new BreadcrumbList node. The breadcrumb items are derived from base (section slug), the entry's title[locale], and Astro.url.href. The WebSite block is a standalone <script> tag injected in HomeView.astro. The Pagefind SearchAction URL template uses the ?q= query param — if Pagefind's client-side search doesn't respond to that param, omit potentialAction or point at a future server-side search endpoint.
