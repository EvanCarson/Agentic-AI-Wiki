What is RAG?

Retrieval-Augmented Generation (RAG) is a technique that supplements a language model's parametric knowledge with documents fetched from an external store at inference time. The model receives both the user query and the retrieved context in its input window, enabling it to produce grounded, verifiable responses without retraining its weights.

RAG separates the knowledge layer from the reasoning layer — a design choice that keeps the model general-purpose while allowing the knowledge base to be updated independently.
