# Chinese Version (i18n) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a full human-quality Simplified-Chinese version of the Agentic AI Wiki: English stays at root URLs, Chinese mirrors under `/zh`, all 22 Field Guide bodies (21 chapters + intro) and all UI chrome translated, shipped only when the complete bilingual verification gate is green.

**Architecture:** Astro built-in i18n (`defaultLocale: en`, `locales: [en, zh]`, `prefixDefaultLocale: false`). English bodies move to `src/content/field-guide/en/`, Chinese to `…/zh/`. `manifest.ts` keeps structure/slugs as single source of truth; `title`/part `name` become `{en,zh}` maps. A small `src/i18n/` module holds locale helpers + a `ui` string dictionary. Page bodies are factored into locale-aware shared components consumed by both the root (en) route tree and a thin `src/pages/zh/` tree. The verify gate is extended to assert per-locale build + en↔zh structural/code-block parity.

**Tech Stack:** Astro 4, TypeScript, node:test (+ `--experimental-strip-types`), node-html-parser, npm, Node 24.

**Phasing:** (1) Infra Tasks 1–9 → (2) Glossary Task 10 → (3) Translation Tasks 11–32 (intro + 21 chapters, each translate→review→fix) → (4) Final bilingual verification + merge Task 33. Nothing merges to `main` until Task 33’s gate is green.

**Branch:** All work on `feat/i18n-zh` (created in Task 1). Spec: `docs/superpowers/specs/2026-05-17-i18n-chinese-design.md`.

```ts
export const LOCALES = ['en', 'zh'] as const;
export type Locale = (typeof LOCALES)[number];
export const DEFAULT_LOCALE: Locale = 'en';

export type Localized<T = string> = Record<Locale, T>;

export function isLocale(v: string): v is Locale {
  return (LOCALES as readonly string[]).includes(v);
}

/** Resolve a localized value for a locale. */
export function tr<T>(val: Localized<T>, locale: Locale): T {
  return val[locale];
}

/** Prefix an internal absolute href for a locale. en is identity; zh gets a /zh prefix. */
export function localizeHref(href: string, locale: Locale): string {
  if (locale === DEFAULT_LOCALE) return href;
  return href === '/' ? '/zh' : `/zh${href}`;
}

/** Map a current pathname to its equivalent in another locale. */
export function switchLocalePath(path: string, to: Locale): string {
  const stripped = path.replace(/^\/zh(?=\/|$)/, '') || '/';
  return localizeHref(stripped, to);
}
```

```js
import { readFileSync, writeFileSync, mkdirSync } from 'node:fs';
import { dirname, join } from 'node:path';
import { fileURLToPath } from 'node:url';
import { parse } from 'node-html-parser';

const ROOT = join(dirname(fileURLToPath(import.meta.url)), '..');
export const OUT_DIR = join(ROOT, 'src/content/field-guide/en');

/** Parse HTML, return [{ page, html }] for every <div> with class "page" and a data-page attribute. Strips dead legacy .page-nav blocks. */
export function extractPages(htmlString) {
  const root = parse(htmlString, { comment: true });
  const nodes = root.querySelectorAll('div.page[data-page]');
  return nodes.map(n => {
    n.querySelectorAll('.page-nav').forEach(el => el.remove());
    return { page: n.getAttribute('data-page'), html: n.innerHTML };
  });
}

function main() {
  const src = readFileSync(join(ROOT, 'legacy/agentic_ai_guide_1.html'), 'utf8');
  const pages = extractPages(src);
  mkdirSync(OUT_DIR, { recursive: true });
  for (const { page, html } of pages) {
    writeFileSync(join(OUT_DIR, `${page}.html`), html.trim() + '\n');
  }
  console.log(`extracted ${pages.length} pages:`, pages.map(p => p.page).join(', '));
}

if (process.argv[1] === fileURLToPath(import.meta.url)) main();
```

- [ ] **Step 3: Replace `scripts/verify-chapters.mjs`** with the per-locale + parity gate

```js
import { existsSync, statSync, readdirSync, readFileSync } from 'node:fs';
import { join, dirname } from 'node:path';
import { fileURLToPath } from 'node:url';
import { CHAPTERS } from '../src/content/field-guide/manifest.ts';

const ROOT = join(dirname(fileURLToPath(import.meta.url)), '..');
const MIN_BYTES = 200;
let failed = 0;
const fail = (m) => { console.error(m); failed++; };
const tooSmall = (p) => !existsSync(p) || statSync(p).size < MIN_BYTES;
const codeBlocks = (html) => (html.match(/<pre[\s\S]*?<\/pre>/g) || []);

if (CHAPTERS.length === 0) fail('MANIFEST regression: CHAPTERS is empty');

// English source bodies (always required).
for (const ch of CHAPTERS) {
  if (tooSmall(join(ROOT, 'src/content/field-guide/en', `${ch.page}.html`)))
    fail(`MISSING/too small en body: ${ch.page}.html`);
}
if (tooSmall(join(ROOT, 'src/content/field-guide/en/intro.html'))) fail('MISSING en intro.html');

// Built pages, per locale present in dist.
const distFg = (loc) => join(ROOT, loc === 'en' ? 'dist/field-guide' : `dist/${loc}/field-guide`);
for (const loc of ['en', 'zh']) {
  const dir = distFg(loc);
  if (!existsSync(dir)) { if (loc === 'en') fail('MISSING dist/field-guide (en)'); continue; }
  const slugs = new Set(CHAPTERS.map(c => c.slug));
  for (const ch of CHAPTERS)
    if (tooSmall(join(dir, ch.slug, 'index.html'))) fail(`MISSING built ${loc} page: ${ch.slug}`);
  for (const e of readdirSync(dir, { withFileTypes: true }))
    if (e.isDirectory() && !slugs.has(e.name)) fail(`ORPHAN ${loc} page: ${e.name}`);
}

// Chinese bodies + parity. Skipped (infra mode) until any zh body exists.
const zhDir = join(ROOT, 'src/content/field-guide/zh');
const zhFiles = existsSync(zhDir) ? readdirSync(zhDir).filter(f => f.endsWith('.html')) : [];
const zhMode = zhFiles.length > 0;
if (zhMode) {
  const need = [...CHAPTERS.map(c => c.page), 'intro'];
  for (const page of need) {
    const en = join(ROOT, 'src/content/field-guide/en', `${page}.html`);
    const zh = join(zhDir, `${page}.html`);
    if (tooSmall(zh)) { fail(`MISSING/too small zh body: ${page}.html`); continue; }
    const enC = codeBlocks(readFileSync(en, 'utf8'));
    const zhC = codeBlocks(readFileSync(zh, 'utf8'));
    if (enC.length !== zhC.length || enC.some((b, i) => b !== zhC[i]))
      fail(`CODE-BLOCK MISMATCH en/zh in ${page}.html (en ${enC.length} vs zh ${zhC.length} blocks)`);
  }
  const complete = [...CHAPTERS.map(c => c.page), 'intro'].every(p => !tooSmall(join(zhDir, `${p}.html`)));
  if (failed === 0)
    console.log(complete
      ? `OK — bilingual complete: ${CHAPTERS.length} chapters + intro per locale, code blocks identical, no orphans`
      : `OK (infra mode) — en complete; zh in progress (${zhFiles.length}/${CHAPTERS.length + 1} bodies)`);
} else if (failed === 0) {
  console.log(`OK (infra mode) — en complete; zh not started`);
}

if (failed) { console.error(`\n${failed} check(s) failed`); process.exit(1); }
```

## Translation Task Procedure (applies to Tasks 11–32)

Each translation task takes one English body `src/content/field-guide/en/<page>.html`
and produces `src/content/field-guide/zh/<page>.html`. The procedure for every
task is identical; only `<page>`/slug differs.

- [ ] **Step A: Read inputs.** Read the full English body and
  `docs/i18n/zh-glossary.md`.
- [ ] **Step B: Translate.** Produce `src/content/field-guide/zh/<page>.html`:
  every HTML tag/attribute/class/id/href byte-identical to the English file;
  every `<pre>…</pre>` block byte-identical (including English code comments);
  all visible prose, headings, captions, table cells, and inline-`<code>`
  *surrounding* prose translated to zh-Hans per the glossary; technical terms
  `中文（English）` on first use. The file must contain the same number of
  `<pre>` blocks as the English source, each identical.
- [ ] **Step C: Self-check.** Run:
  `node -e "const fs=require('fs');const p=process.argv[1];const cb=s=>(s.match(/<pre[\s\S]*?<\/pre>/g)||[]);const en=cb(fs.readFileSync('src/content/field-guide/en/'+p+'.html','utf8'));const zh=cb(fs.readFileSync('src/content/field-guide/zh/'+p+'.html','utf8'));if(en.length!==zh.length||en.some((b,i)=>b!==zh[i])){console.error('CODE MISMATCH');process.exit(1)}console.log('code blocks identical:',en.length)" <page>`
  Expected: `code blocks identical: <n>`. Fix until it passes.
- [ ] **Step D: Independent review.** Dispatch a review subagent (separate
  context) with the English source, the zh output, and the glossary. It must
  verify: semantic accuracy (no added/dropped/changed meaning), glossary &
  terminology consistency, every HTML tag/attr and every `<pre>` block
  byte-identical, completeness (no skipped sections), fluent professional
  zh-Hans register. It returns ✅ or ❌ with specific line refs.
- [ ] **Step E: Fix loop.** If ❌, fix the cited issues and re-review (Step D)
  until ✅.
- [ ] **Step F: Build gate.** Run `npm run build` (exit 0) and
  `npm run verify` (must not report a CODE-BLOCK MISMATCH or
  MISSING zh body for `<page>`).
- [ ] **Step G: Commit.** `git add src/content/field-guide/zh/<page>.html && git commit -m "i18n(zh): translate <page> (<slug>)"`
