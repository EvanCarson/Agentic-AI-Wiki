# llms.txt Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Publish `/llms.txt` and `/zh/llms.txt`, generated at build time from the six section manifests, so AI assistants have a titled, summarised map of every page.

**Architecture:** A pure builder (`src/lib/llms-txt.ts`) turns a `Sources` bundle of manifests into a document model and renders it as llmstxt.org Markdown; a one-line glue module (`src/lib/llms-sources.ts`) binds the real manifests; two thin Astro endpoints write the files. Unit tests run over fixtures under `node --test`; an integration test checks the built files against `dist/` and skips when there is no build.

**Tech Stack:** Astro 5 static endpoints, TypeScript under `node --experimental-strip-types`, `node:test`.

Spec: `docs/superpowers/specs/2026-09-01-llms-txt-design.md`. Issue: #184.

## Global Constraints

- Imports inside `src/lib/llms-txt.ts` must carry `.ts` extensions and must not import `src/i18n/ui.ts` (extensionless imports; will not load under node).
- Output format: H1, blank, `> summary`, blank, detail paragraphs, then `## <Section>: <Group>` headings with `- [title](absolute url): note` lines; final section is literally `## Optional` in both locales.
- Every page URL is absolute on `site` and ends in `/`; Chinese page URLs carry `/zh/`.
- Section names must equal the nav strings in `src/i18n/ui.ts`: en `Concepts / Deep-Dives / Playbooks / Operations / Field Guide / AI Blog`, zh `概念 / 深度剖析 / 实战手册 / 运维 / 实战指南 / AI 博客`.
- No `vercel.json` change (Vercel serves `.txt` as `text/plain; charset=utf-8`, verified live 2026-09-01).
- Changelog entry file dated the merge day, bilingual, in the same PR.
